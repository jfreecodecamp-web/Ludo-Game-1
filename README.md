# Ludo Game (JavaScript)

## Description
A browser-based Ludo game built using JavaScript. Implements core game mechanics including dice rolls, player turns, and movement logic.

## Features
- Turn-based gameplay
- Token movement logic
- Basic game rules implemented

## Tech Used
- JavaScript
- HTML
- CSS

## How to Run
1. Download project
2. Open index.html in browser
